# v2.2.0 — 本地知识库 + .harness 治理体系 + 8 宿主适配

> **本文件为事后回填。** v2.2.0 于 2026-06-15 发布到 npm
> （`@wychmod-cn/testcase-generator-skill`），但发版当时未回填日志，
> `.harness/changelogs/v2.2.0-TEMPLATE.md` 一直停留在占位状态。
> 内容依据 2026-06-08 ~ 06-16 的提交历史与当时的 README 版本历史重建。

## 新增（Added）

- **本地知识库 `knowledge/`**（v1 触发式 BM25，零外部依赖）：`build_index.py` 索引构建、
  `search.py` 触发词检索与 Top-K 命中片段、`llm-ingest-template.md` 手动录入模板。
- **`knowledge/scripts/ingest.py`**：通过用户自配置的 `TEST_GEN_LLM_CMD` 命令自动抽取知识条目，
  不绑定任何 LLM SDK。
- **`scripts/incremental_code_scan.py`**：解析 unified diff、提取新增代码行、按 token 重叠匹配
  PRD 需求，并标记潜在 bug 风险信号。
- **`.harness/` 治理体系**：项目宪法（`AGENTS.md`）、7 个 reins 角色、文档一致性护栏脚本、
  打包钩子与端到端评测。
- **`docs/` 文档中心**：架构、开发、运维、质量与 changelog 五个分区。
- **`.skill` 打包链路**：`devtools/package_skill.py` 产出 `.skill` 与 `.zip` 双产物并交叉校验。
- `test-generator activate all`：一次性激活全部受支持宿主。

## 改动（Changed）

- **宿主适配从 5 个扩展到 8 个**：新增 `codebuddy`（腾讯云 AI 代码助手完整适配）、
  `cursor`（软适配，`.cursorrules`）、`windsurf`（软适配，`.windsurfrules`）。
- `skill.manifest.json` 升级为分发与宿主路由的统一定义源，补齐运行时文件清单与分发排除规则。
- README 重写为面向使用者的完整文档，并标注 npm 发布元数据。
- `activation` 测试覆盖增强；仓库清理误跟踪产物并按 `docs/` 规划重组。

## 修复（Fixed）

- `incremental_code_scan.py` 会把 Python 函数 docstring 误识别为 PRD 需求，已增加 docstring 区间过滤。
- 清理仓库中误跟踪的本地产物。

## 移除（Removed）

- 无。

## 已知限制（Known Limitations）

- **三处版本号当时并不一致**：`package.json` 为 `2.2.0`，而 `SKILL.md` 与
  `skill.manifest.json` 仍停留在 `2.1.0`。该缺陷直到 v2.3.0 引入版本同步器才被系统性修复。
- 知识库索引 `knowledge/index.json` 为本地构建产物，不入分发包，首次使用需先重建。
- 本地宿主镜像目录会随 canonical 内容更新而陈旧，当时没有任何检测机制。

## 升级注意（Upgrade Notes）

  使用 `test-generator activate <host>` 重新导出可拿到 8 宿主支持。
- `SKILL.md` 的 description 已扩展知识库相关触发场景。
