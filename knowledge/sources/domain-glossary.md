# 业务术语表（示例）

这是 testcase-generator 知识库的示例术语表。**用户应替换为自己的项目术语**。

## 用户与权限

| 术语 | 定义 | 备注 |
|---|---|---|
| 普通用户 (Regular User) | 已注册但未付费 | 默认角色 |
| VIP 用户 (VIP User) | 付费会员 | 享有高级功能 |
| 超级管理员 (Super Admin) | 平台运营人员 | 可访问后台 |
| 访客 (Guest) | 未登录用户 | 仅可浏览公开内容 |

## 订单状态机

| 状态 | 触发事件 | 下一步合法状态 |
|---|---|---|
| 待支付 (Pending) | 用户提交订单 | 已支付 / 已取消 / 已超时 |
| 已支付 (Paid) | 支付成功回调 | 已发货 / 退款中 |
| 已发货 (Shipped) | 物流揽收 | 已签收 / 退款中 |
| 已签收 (Received) | 用户确认收货 | 已完成 / 退款中 |
| 退款中 (Refunding) | 用户申请退款 | 已退款 / 拒绝退款 |
| 已退款 (Refunded) | 退款完成 | 终态 |
| 已取消 (Cancelled) | 用户主动取消 / 超时 | 终态 |

## 支付相关术语

- **SKU (Stock Keeping Unit)**：商品最小库存单位，每个 SKU 对应一个价格
- **结算 (Settlement)**：T+1 结算到商户账户
- **手续费 (Commission)**：平台收取的比例，标准类目 5%
- **退款时效 (Refund Window)**：已签收后 7 天内可申请

## 易混淆概念

| 相似概念 | 区别 |
|---|---|
| 用户名 vs 昵称 | 用户名唯一且不可改；昵称可重复且可改 |
| 订单号 vs 交易号 | 订单号用于业务；交易号用于支付对账 |
| 优惠 vs 折扣 | 优惠是营销活动；折扣是定价策略 |
