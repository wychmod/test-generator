# 登录模块 PRD

## 背景

用户需要通过账号和密码登录系统，以访问个人资料和订单信息。

## 功能需求

- REQ-LOGIN-001：已注册且状态为 active 的用户可以使用正确账号和密码登录。
- REQ-LOGIN-002：账号或密码为空时，系统应拒绝提交并显示字段级错误。
- REQ-LOGIN-003：密码错误时，系统应返回认证失败，不得返回 token。
- REQ-LOGIN-004：连续 5 次密码错误后，账号锁定 30 分钟。
- REQ-LOGIN-005：用户名长度为 3-50 个字符，只允许字母、数字、下划线。

## 非功能需求

- 登录响应时间 P95 小于 800ms。
- 错误提示不得泄露账号是否存在。

## 期望测试输出

生成 Markdown 标准完整用例，覆盖正向、负向、边界值、安全锁定和追溯矩阵。
